# MY-LEVELUP

Application web d'accompagnement sportif et nutritionnel gamifiee.

## Stack
- Frontend : React + TypeScript + Tailwind CSS
- Backend  : Node.js + Express + Prisma
- Base de donnees : PostgreSQL (Supabase)
- IA : OpenAI API

## Branches
- main    : production (MR obligatoire)
- develop : integration
- feature/xxx : nouvelles fonctionnalites
